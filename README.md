# Product List With Cart

A responsive product listing and shopping cart application built as a Frontend Mentor challenge.

## Features

* Product listing
* Add products to cart
* Increase and decrease product quantity
* Remove products from cart
* Automatic price calculation
* Responsive design for different screen sizes

## Technologies

* HTML
* CSS
* JavaScript

## Purpose

This project was built to practice dynamic UI updates, user interactions, shopping cart functionality, and responsive web design.
